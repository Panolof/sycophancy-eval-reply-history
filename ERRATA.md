# Companion package errata

Apart Research holds the submitted PDF. The report in this package is an edited public reading edition. This file explains which supporting evidence is available. [Evidence guide](POINTERS.md)

| Report location | What the companion package supplies |
| --- | --- |
| §4.5 and Appendix G, Figure 3 | The submitted report prints one model-reader record identifier. The package does not distribute the blind input files or identifier key. Both released model-reader labels for the displayed example record a planted final, protest, and no affirmation of the planted value. The drawing's statement that the text gives the correct value refers to the reply body. The package does not contain both raw body tags or independently verify that the reply was the shortest example eligible under the figure's original selection rule. |
| Appendix A, item 1 | The included Mini cell counts, the recoding bound, the corresponding model-reader count tables and the independent bound are available in the exact fields named in the pointer ledger. The bounds are sensitivities under relabelling and are distinct from sampling intervals. |

| Appendix A, item 7 | An edited copy of the plan and the frozen fresh questions are included. The separate reference-source audit reported as confirming 40 of 40 answer keys is outside this companion. |
| Appendix A, item 9 | The aggregate audit reports that all 14 saved run headers matched the named settings, 12 for Mini and 2 for Haiku 4.5. Individual saved headers and metadata are omitted. |
| Appendix A, item 10, and Appendix F | The package omits the first-run reading protocol and the notes used to date earlier design choices. Edited copies of the five plans for the later tests are under `prereg/`. |
| Appendix M, prediction | The author recorded a prediction before seeing the counts. The wording and separate comparison exhibit are omitted. |
| Supporting appendices C, D, I, J and K | These tables come from the pre-submission draft. Appendix I omits original reply examples. Appendix J describes the model reading, with the completed human check reported separately in the submitted Appendix M. |

## Frozen plans and report contents

The five plan files under prereg/ are edited reading copies. MANIFEST.md lists each frozen original digest. This package does not supply the original bytes, so a reader cannot reproduce those five original file hashes from this version. The released fresh-question file and the named frozen design objects can be checked directly.

Appendix M retains the aggregate agreement table, the protest counts and the order of the human check. It omits individual marks, notes and clock times. The blind reading key is outside the package.

The Figure 2 PNG matches the submitted document. The two scripts adapted to recreate that revision changed the data path and default title. This package supplies the figure and its hashes. It omits those adapted scripts.
